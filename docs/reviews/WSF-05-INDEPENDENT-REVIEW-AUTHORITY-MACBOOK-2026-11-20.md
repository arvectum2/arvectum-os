## Implemented

Reviewer-side private SQLite store, independent from operator register files: exclusive explicit initialization, trust configuration digest, genesis pin, FULL synchronous transactions, signed append history, monotonic head derived from validated chain, persistent exact reservation, atomic compare-and-set and persistent revoke. No silent reinitialization, server-side clock, competing reservation denied, old ticket cannot move head backwards. Reserve before primary write and before local journal; exact resume after a crash between reservation and journal. Pending independent reservation blocks read. Operator-side source/backup/journal gates remain; no stale cache on authority outage. Bounded canonical RPC: head/read_head/check/reserve/commit only. No request-controlled path, trust, server clock, initialization, signing, revocation or reset. Authentication and transport deliberately external to protocol; not an exposed endpoint. Bound scope DEC-004/005 historical indexes and RSK-002 evidence only; no actual Assignment, payment or generalized approval. Key and contract rotation not implemented.

## Device boundary required before production

MacBook can reach Mac mini over already configured strict-host-key SSH, both have Python 3.14.10 available and system OpenSSH 10.5. ARC can currently run commands on both devices. Merely putting a key or SQLite file on MacBook DOES NOT establish independent authority. Separate protected local account / process, operator without administrative or file access to that account, separately controlled reviewer signing key, pinned public key/transport identity and owner-reviewed trusted configuration are required. The human reviewer must control signing (for initial pilot an encrypted key under exclusively controlled access, never passphrase in chat/ARC, no unattended signing). A separately enabled service under protected account may validate signed tickets and store head; no private signing material needed for RPC. Future hardware-backed signer requires separate format/verifier review. Actual account separation, effective access rights, ARC administrative reach, key custody/recovery and key revocation must be verified, not inferred from device choice. Do not create production credentials or grant broader remote shell.

Proposed transport: authenticated restricted command with pinned host key and per-service client identity; no general shell/forwarding, no inbound public listener or new exposure, exact command/environment/request bounds, server-side authority composition. Actual operator P7.04 eligibility checked on Mac mini AND separately enforced reviewed register/actor/expiry/revocation at authority side; no conversion of read capability into write permission. Keep legacy exact reads until separately approved effective contract and deployment. Real installed operator and projection must connect the bounded protocol with canonical Company writers, verified external volume/maintenance and source/backup verification. Test channels do not authenticate the asserted operator string. No independent service or authenticated cross-device RPC installed yet.

## Continuity / security limits

MacBook sleep, outage or revocation fail closed for new admitted read/update; do not fall back to mutable latest source. Preserve pending reservation/journal for exact forward recovery. If revoked/expired mid-transition, no automatic rollback, no re-signing without actual authorized resolution. Store protects against operator-side replay and rollback while independently protected MacBook state is intact. Full rollback/compromise of MacBook and its trust configuration is not detected by SQLite alone; before restoration require independently held latest checkpoint/head and actual owner verification, no automatic recovery from older copy. Independent backup/restore and re-enrollment procedure remains a gate. Historical signature verification currently linear in bounded history; performance and long-run retention need actual evidence. No claim of protection against privileged compromise of both devices.
