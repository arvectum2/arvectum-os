Candidate evidence, not an approved Product Contract, production implementation or owner acceptance. Base canonical 37ccdcbff8da6ccad2d7e471c4a390f97039a27a; feasibility proposal in draft PR #63.

## Actual test evidence

Python standard-library TLS server/client on an ephemeral IPv4 loopback port; temporary CA, server and two client certificates, strict server certificate/hostname verification, mutual TLS and exact registered client certificate hash from the actual TLS socket. Synthetic P7.04 stores use fresh private physical temp directories; no production store or provider. Explicit remote-only P7.04 grant; local grant cannot substitute. Local fixture-issued random single-use admission code, 2-minute lifetime. In-memory bounded SessionStore with 30s idle/90s absolute lifetime and exact credential/grant/device binding; no real user verification. Protected read returns one synthetic overview; all other routes denied except session bootstrap/logout. No persistent credentials exported, no logging of codes or cookies. No new dependency or production listener.

10/10 real TLS scenarios PASS; 30/30 combined spike, P7.04 and Workspace-config regression tests PASS on Mac mini Python 3.14. Negative cases: missing client certificate, invalid trust/hostname, other valid but unregistered certificate, forged forwarding headers, local-only grant, absent/wrong/replayed/expired code, wrong Host/Origin, missing session or CSRF, unadmitted read and write routes, session rotation/idle/absolute expiry, credential/device revocation, grant replacement, admission expiry. Temporary directory path initially rejected due to macOS /var symlink; fixed fixture path resolution, not P7.04. Initial certificates lacked required authority key identifier; corrected fixture CA/extensions rather than disabling strict verification. All fixture listeners shut down and temp material cleaned.
